# EasySM

This repo contains three software artefacts:

1. The folder `agda-only` contains a prototype of a pure Agda-version of the EasySM framework for EUTxO automata contracts.
2. The folder `agda2hs` contains a prototype of a combined Agda and Haskell version of the EasySM framework for EUTxO automata contracts.
3. The folder `animation` contains an EasySM contract animation framework that animates traces produced by the contract simulator from the `agda2hs` folder.

This is work in progress.
